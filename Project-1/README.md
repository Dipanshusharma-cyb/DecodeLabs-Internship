# Project-1: Password Strength Checker

## Overview
A Password Strength Checker built using Python and Streamlit. The application analyzes passwords and provides feedback on their strength.

## Features
- Password strength analysis
- Weak, Medium, Strong classification
- User-friendly Streamlit interface

## Technologies Used
- Python
- Streamlit

## Run

streamlit run app.py
